# my-project-super-trunfo-VictorHugo
Super Trunfo - MMORPG DED em C 🎮 Um jogo de Super Trunfo no estilo MMORPG DED, desenvolvido em C. Os jogadores exploram um mundo, enfrentam desafios e duelam com cartas baseadas em atributos. Inclui sistema de progressão, batalhas estratégicas e eventos aleatórios. Criado para aprimorar lógica, estruturas de dados e manipulação de memória.
